About SpendWise

What this project is, how it is built, and who built it.

Home About

A small tool for a real problem

Zyada log apna kharcha isliye track nahi karte kyunki apps bahut heavy hote hain - signup, permissions, ads. SpendWise iska ulta hai: ek page kholo, entry daalo, ho gaya.

Project poori tarah front-end hai. Koi backend ya database nahi. Har transaction browser ke LocalStorage me JSON ke roop me store hota hai, aur JavaScript usi data se totals, budget progress aur charts banata hai.

Ye project HTML structure, CSS layout aur JavaScript logic - teeno ko ek saath practice karne ke liye banaya gaya hai, ek aise use case par jo rozmarra ki zindagi se juda hai.

Features

What the app can do

Add and delete entries

Full create and delete flow with validation on every field before saving.

Automatic calculations

Income, expense, balance, monthly totals and averages are computed on load.

Budget warnings

Colour changes and messages at 50%, 75%, 90% and beyond the limit.

Four chart types

Doughnut, pie, bar and line charts generated from live stored data.

Search and filter

Keyword search combined with type and category filters on one list.

Form validation

Inline error messages, email and phone patterns, and a success confirmation.

Process

How the project was built

Planning the pages

Seven pages were decided first, each with a clear job, so navigation stays simple.

Designing the shared layout

One global stylesheet holds the colour tokens, navbar, cards, forms and footer used everywhere.

Writing the core logic

A single main.js file handles storage, calculations and formatting. Every page reuses it.

Page-level scripts

Each page has its own script that reads from the core and renders only what that page needs.

Responsive pass

A separate stylesheet handles tablet and mobile breakpoints, including the collapsible menu.
